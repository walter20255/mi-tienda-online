# 🛒 Tienda Online de Mueblería

Sitio web desarrollado para simular una tienda online de muebles, basado en un negocio real. Permite visualizar productos, precios e interactuar con la interfaz mediante funcionalidades dinámicas.

---

## 🚀 Funcionalidades

* Visualización de catálogo de productos
* Diseño responsive (adaptado a dispositivos móviles)
* Interacción con JavaScript (botones y acciones dinámicas)
* Interfaz clara y orientada al usuario

---

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

---

## 📌 Descripción

Este proyecto fue desarrollado como práctica de desarrollo web, tomando como base una mueblería real. El objetivo fue simular una tienda online, aplicando conceptos de diseño, estructura web y lógica de interacción con el usuario.
